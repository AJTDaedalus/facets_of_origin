# Playtest Session Logs Index

This folder contains the complete transcripts and mechanical resolution logs for all twenty playtests conducted for the *Oraga Night* masquerade adventure module. 

Each session log records everything said at the table by the player and Mirror Master (MM) personas, along with the mechanical execution of rolls, postures, magic casting, and combat exchanges resolved on the server.
