### Engine API (for APP)
All functions take the session's `ruleset` (a `MergedRuleset`) first. Tests/replays may pass fixed `dice=[...]` (2 + extra dice), `damage_dice=[...]`, or `rng=random.Random(seed)`. Every result has `to_dict()` (or `roll_result_to_dict`) that is JSON-safe.

**Rolls — `app.game.engine`**
- `resolve_roll(ruleset, *, stat_value, stat=None, knack=False, bonus=0, difficulty="Standard", sparks=0, help=0, borrowed_trouble=False, extra_dice=0, dice=None, rng=None, kind="roll", description="") -> RollResult` — keep best two; `modifier` = stat+knack+bonus capped +4 (`capped` flag); `outcome` full_success|partial_success|failure; `natural_high` forces full_success; `natural_low` + failure sets `graceful_fail_auto`. Raises ValueError on Help>1, negatives, bad difficulty/dice. Does **not** debit Sparks.
- `roll_character(ruleset, character, stat, **resolve_roll kwargs)` — reads the stat and debits Sparks.
- `resolve_avoid(ruleset, *, stat_value, stat, difficulty=None, knack, sparks, help, borrowed_trouble, dice, rng)` — `extra["text"]` = the tier's line.
- `roll_result_to_dict(result)`; `roll_expr("2d8+1", rng, fixed)`.
- `GameSession.confirm_natural_two_graceful_fail(player, roll_dict)` awards the Spark when `outcome=="failure" and natural_low`.

**Character — `app.game.character`**
- `create_character(ruleset, *, name, player_name, facet, second_stat, class_id=None | custom_class={name, concept, knack, talents:[2], kit:[ids], signature?}, background_id=None | custom_background={name, knack, specialty, description}, lineage="human", gifted=None, gift_domain=None, talent_choices={"weapon_master": kind, "wider_domain": domain}, magic={"domain", "signature_workings":[2]}, kit=None, coin=None, rng=None) -> (Character|None, errors)`.
- Derived (all take ruleset): `hp_max`, `slots_total`, `slots_used`, `slots_free`, `items_to_drop`, `curio_limit`, `armor_value`, `weapon_die`, `is_ranged`, `damage_bonus`, `traditions`; `to_client_dict(ruleset)` adds `derived{hp_max, slots_*, armor, weapon_die, ranged, damage_bonus, curio_limit, items_to_drop, grit_die, warnings}`.
- Level: `level_up(ruleset, *, kind="talent"|"improve"|"signature", talent_id, choice=None, teacher=False, stat=None (required at 4/8), signature_working=None (casters at 5/9), hp_roll=None (None=average), extra_talents=None (Polymath)) -> errors` (no change on error; signature pick is forced at level 3). `can_respec(ruleset)`, `respec(ruleset, talents=[{id, improved?, choice?}], magic=None) -> errors`. `planned_signature(ruleset, ch)`.
- HP/death: `take_damage(ruleset, n, allow_unstoppable=True) -> {hp_before, hp_after, damage, dropped, unstoppable_used}`; `fall(ruleset, wound=None, dice=None, rng=None) -> {wound, hold_on: RollResult, items_to_drop}` (rolls the wounds table when `wound` is None); `hold_on(ruleset, dice, rng, sparks)` (sets `status` ok/out/dying; `extra["status"]`); `tend(field_surgeon=False)`; `death_choice(ruleset, "scar"|"heroic", scar=None)`; `heal(ruleset, n)`; `breather(ruleset)`; `night_rest(ruleset, wound_index=0)`; `add_wound(name)`, `remove_wound(i)`; `add_fatigue(ruleset, n)` (raises when no slot). `status` ∈ ok|out|dying|dead.
- Sparks/uses: `spend_spark(n)`, `earn_spark(n)`, `start_session(ruleset)` (Sparks → 3, session+scene uses reset); `use_talent(ruleset, id, period=None, limit=None) -> uses left|None` (raises when spent/not held); `uses_remaining(...)`; `reset_uses(ruleset, "scene"|"rest"|"session")`. Talent-use keys: `id` for the talent's own period, `id@scene` etc. for improved-form abilities.
